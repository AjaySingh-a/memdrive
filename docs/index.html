memdrive

Free Google Drive backup and restore for claude-mem, the long-term memory for Claude Code.

claude-mem stores your memory on your computer. memdrive keeps a copy in your own Google Drive, automatically, so it survives a broken laptop and follows you to a new computer. It is free and open source, and your data never touches anyone else's server.

Install

Install claude-mem first, then:

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/AjaySingh-a/memdrive/main/install.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/AjaySingh-a/memdrive/main/install.ps1 | iex

memdrive asks you to choose a backup password, then your browser opens to allow access to Google Drive. It makes the first encrypted backup and turns on automatic backups. You only run the install command once.

Commands

After installing, use these whenever you need them:

memdrive status         is everything working?
memdrive backup         back up now
memdrive list           your backups on Google Drive
memdrive restore        bring back this computer's latest backup
memdrive restore NAME   bring back another computer's backup
memdrive setup          connect Google Drive and turn on automatic backups
memdrive disconnect     stop backups and remove Google Drive access
memdrive password       change the backup password
memdrive update         update now (memdrive also updates itself daily)
memdrive help           all commands

To use another Google account, run memdrive disconnect, then memdrive setup. To uninstall, run memdrive disconnect and delete the .memdrive folder in your home folder.

What it does

  • Checks every hour, and backs up when your memory has changed and the last backup is more than 6 hours old.
  • Saves backups to Google Drive → memdrive → your computer's name.
  • Keeps your newest 5 backups always, and removes ones older than 30 days.
  • Encrypts every backup with your backup password before upload, so nobody can read it from Drive.
  • Restores on any computer with memdrive restore and your backup password.

Your data

memdrive uses Google's drive.file permission, so it can only see the files it created. It cannot read anything else in your Drive. There is no memdrive server: backups go straight from your computer to your Google Drive, encrypted with a password only you know. Read the privacy policy.
